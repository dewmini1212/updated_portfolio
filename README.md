## Run Locally

```bash
# Clone the repository
git clone https://github.com/dewmini1212/updated_portfolio.git

# Open the project folder
cd updated_portfolio

# Open index.html in your browser
```

No build step or dependencies are needed. You can also use a local server such as the VS Code **Live Server** extension.

## Deployment

The site is deployed on **Vercel** and redeploys automatically on every push to the `main` branch.
